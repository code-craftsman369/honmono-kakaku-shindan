# 本物価格診断

自然栽培米・味噌・へしこなど「本物の手間」に、原価（時間・手間・希少性・リスク）から逆算して価格をつけるためのツールです。

一回の収穫・仕込みでできる数量、工程ごとの作業時間、材料費、希少性・リスク・裏付けを入力すると、

- 原価と適正価格レンジ
- その価格で売った場合の実質時給
- 4R+5次元思考に基づく「価格の物語」（POP・SNSにそのまま使える説明文）

を診断します。外部APIには接続せず、すべてブラウザ内のルールベース処理で完結します。

## 使い方

`index.html` をブラウザで開くだけで動きます（ローカルでは `本物価格診断を起動.command` をダブルクリック）。
